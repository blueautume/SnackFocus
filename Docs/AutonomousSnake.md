# 蛇行：动态环路专注伴侣

## 体验流程

进入应用先选地图和速度，点击「开始观看」后才运行。运行中隐藏地图、速度及设置入口，只保留像素游戏、分数、计时、暂停 / 继续和重开。地图与速度由只读属性暴露，运行中的修改请求也会被会话层拒绝。

重开使用自绘像素确认窗口。打开时冻结游戏、身体摆动、食物呼吸及计时；取消恢复原先的运行 / 暂停状态，确认后返回选择页，保留上次选择但不自动开局。通关后的重开同样需要确认。

只提供动态环路一种策略。铺满或意外碰撞后停止并显示休息提示，不自动开始下一局。后台 / 暂时失活会暂停，返回不补跑后台步数。前台运行保持常亮，暂停 / 结束后恢复原设置。提醒仅在应用内，无通知或联网权限，进程退出不恢复进度。

## 地图与三档速度

| 地图 | 格数 / 边界 | 慢速 6 步/秒 | 中速 10 步/秒 | 快速 16 步/秒 |
| --- | --- | --- | --- | --- |
| 无边原野 | 16 × 24，四边互通 | 95–104 分钟 | 57–63 分钟 | 35–39 分钟 |
| 口袋原野 | 12 × 18，四边互通 | 28–33 分钟 | 17–20 分钟 | 10–13 分钟 |
| 四面围墙 | 16 × 24，四条边均为墙 | 97–105 分钟 | 58–63 分钟 | 36–40 分钟 |
| 横向回廊 | 16 × 20，左右互通、上下有墙 | 65–73 分钟 | 39–44 分钟 | 24–28 分钟 |

选择的是速度，不是倒计时时长。缩略图和实际棋盘均用实线表达墙、虚线表达互通边。逻辑邻接、基础闭环、动态换边与渲染遵守横纵独立的边界规则。

## 模拟估时与可复现数据

使用生产引擎，每张地图 256 个固定种子，共 1,024 局全部铺满。统计逻辑步数 P10 / P50 / P90，再除以实际步速；范围为 P10 向下、P90 向上取整到分钟，典型时间为 P50 四舍五入。

表中表示样本中间约 80% 的常见区间，不是保证的上下限、固定计时器或系统闹钟。随机食物、暂停和设备调度可能改变实际用时。手机只读取预先生成的数据，不临时跑模拟。

- 生产表：[SnakeDurationEstimates.swift](../iOSLab/SnakeDurationEstimates.swift)
- 原始每局步数、种子、分位数及源码哈希：[SnakeDurationSimulation.json](SnakeDurationSimulation.json)
- 重现模拟并更新表：Scripts/estimate-snake-duration.sh --write
- 快速完整性 / 过期检查：Scripts/check-snake-duration-estimates.sh

生成脚本使用不可变的生产源码副本，写入前复核哈希。完整性检查核对真实地图拓扑、真实速度及全部原始分位数，并拒绝与引擎不一致的旧数据。报告中的 repository base commit 是生成时工作分支的基点，生产源码以 engineSHA256 为准。

## 动态环路与铺满性质

先构造覆盖所有格子的闭环。完全环绕地图使用随机方向、平移及镜像的蛇形闭环；存在墙的地图保留一列作为回程轨道，必要时转置。平移只允许发生在互通轴，墙不会被当作捷径。

蛇尾到蛇头沿闭环保持顺序。每步可以走合法邻居中的捷径，但不得越过食物或蛇尾；仅当本步不增长、蛇尾离开时可进入旧尾格。没有捷径时走安全的环路后继。

新食物出现后，有限搜索尝试成对的局部四格换边。中间拆分状态不会安装。最终候选必须为覆盖所有格子的单一合法闭环，保持完整身体次序，不增加头到食物的前向距离，并真正改变无向边集合。每颗食物最多尝试 136 次，失败即保留旧环。

两颗食物之间冻结闭环，前向食物距离每步严格减少，至多一圈内进食。每次进食增长一格，因此最终铺满。该性质针对当前四张地图及合法初始状态，不推广到任意障碍图。

设计参考 [John Tapsell 的安全环路与捷径](https://johnflux.com/2015/05/02/nokia-6110-part-3-algorithms/) 和 [Winning Snake: Design Choices in Multi-Shot ASP](https://doi.org/10.1017/S1471068424000267) 的安全循环思路。引擎为独立 Swift 实现，没有模型文件、外部求解器或网络依赖。

## 像素界面与动画

- LCD 底色和微像素轮廓。设置入口、策略选择和底部策略 / 填充文字栏均已移除。
- 连续蛇身左右摆动，头部加宽且双眼标明朝向，末端数节收尖。展示不改变逻辑占用。
- 24fps 视觉插值，食物以 1.4 秒周期从小十字缩放成像素圆。活动单调时钟使暂停、后台和结束精确冻结；减弱动态效果时不摆动、不呼吸。
- 仅互通轴取模，墙轴直接插值并裁剪，长蛇多次穿边不会产生跨屏连线。
- 选择页、按钮、休息提示、确认框统一使用中文像素字体、矩形边框、反色选择、硬像素投影和按下位移。没有系统 sheet、alert 或原生 Picker。
- 字体为 [Fusion Pixel](https://github.com/TakWolf/fusion-pixel-font) 12px 等宽简体中文原版，版本 2026.10.25，SIL OFL 1.1。字体与完整许可随应用打包，来源及校验值见 iOSLab/Fonts/FusionPixel/README.txt。
- VoiceOver 读出地图、真实步速、估时及正确边界。确认时后层控件同时禁用并从无障碍树隐藏，焦点进入弹层。窄屏 / 横屏可纵向滚动。

## 验证

生产引擎检查完成 2,048 局：四图各 256 局，加上 1,024 局小尺寸 / 奇偶尺寸 / 横纵边界组合检查，全部铺满，无自撞、穿墙或食物进度异常，目录地图所有种子均有真实中盘重规划。

独立估时运行另完成 1,024 局。完整性检查验证哈希、原始样本、分位数及真实速度换算，隔离副本中的源码变化会被识别为过期。

视觉检查覆盖成长、头尾、摆动、食物缩放、减弱动态效果、四面围墙、单轴互通、多次穿边及实际地图连续状态。会话检查覆盖初始不运行、运行中锁定选择、确认冻结、取消恢复 / 保留暂停、确认回选择页、前后台、通关和常亮恢复。

模拟器已核对选择页不自启、换图估时变化、选速后开始、运行控件精简、重开确认 / 取消 / 返回选择、中文像素字体及四面墙体的实际显示。模拟估时不等于真机完整绘制性能或长期耗电测试。

验证与构建命令：

    Scripts/check-snake.sh
    Scripts/check-snake-visuals.sh
    Scripts/check-snake-duration-estimates.sh

    xcodebuild -project iOSLab.xcodeproj -scheme iOSLab \
      -configuration Debug -sdk iphonesimulator \
      -destination 'generic/platform=iOS Simulator' \
      CODE_SIGNING_ALLOWED=NO build

## Debug 预览

普通 Debug 和全部 Release 启动均等待选择。仅显式 Debug 预览可绕过：

- --snake-map=meadow|pocket|courtyard|passage 和 --snake-speed=calm|steady|flow 设置初选。
- --snake-preview-shape、--snake-preview-midpoint、--snake-preview-near-full、--snake-preview-filled、--snake-preview-last-bite 使用真实引擎推进预览。
- --snake-preview-static 暂停显示，--snake-preview-setup 强制保留选择页。
