# 蛇行：动态环路专注伴侣

## 体验流程

进入应用先选地图和速度，点击「开始游戏」后才运行。运行中隐藏地图、速度及设置入口，只保留像素游戏、分数、计时、暂停 / 继续和重开。地图与速度由只读属性暴露，运行中的修改请求也会被会话层拒绝。

重开使用自绘像素确认窗口。打开时冻结游戏、蛇身花纹与摆头、食物呼吸及计时；取消恢复原先的运行 / 暂停状态，确认后返回选择页，保留上次选择但不自动开局。通关后的重开同样需要确认。

只提供动态环路一种策略。铺满或意外碰撞后停止并显示休息提示，不自动开始下一局。后台 / 暂时失活会暂停，返回不补跑后台步数。前台运行保持常亮，暂停 / 结束后恢复原设置。提醒仅在应用内，无通知或联网权限，进程退出不恢复进度。

## 地图与三档速度

全部地图统一 16 × 24 格，借鉴 Snake II 经典迷宫轮廓适配竖屏，包括无边原野、四面围墙、双横杠、交错隔墙、双竖栏、多层通道。四面围墙占用最外圈一格，其他迷宫用实际墙格组成障碍，空白边缘仍可对向穿出。蛇和食物不能进入墙格，铺满目标只计算可玩格。

选择页采用六张纯地图缩略图，视觉上不显示名字、说明或尺寸。共享墙块组件在缩略图和游戏内绘制相同风格的实心像素墙格，外围墙与内部墙不再用不同的细线表示。地图名称及拓扑仍可由 VoiceOver 读出。

三档速度为「舒缓」「适用」「激进」，实际速度分别为 6 / 10 / 16 步每秒，界面只显示档名和模拟分钟范围。默认无边原野、适用；点击「开始游戏」前不运行。选择页删去顶部提示、步速说明、重复预计时间和模拟说明，使用可伸缩间距分配地图、速度、按钮的空间，紧凑屏幕可滚动。

## 模拟估时与可复现数据

使用生产引擎，每张地图 256 个固定种子，共 1,536 局全部铺满。统计逻辑步数 P10 / P50 / P90，再除以实际步速；范围为 P10 向下、P90 向上取整到分钟，典型时间为 P50 四舍五入。

表中表示样本中间约 80% 的常见区间，不是保证的上下限、固定计时器或系统闹钟。随机食物、暂停和设备调度可能改变实际用时。手机只读取预先生成的数据，不临时跑模拟。

- 生产表：[SnakeDurationEstimates.swift](../iOSLab/SnakeDurationEstimates.swift)
- 原始每局步数、种子、分位数及源码哈希：[SnakeDurationSimulation.json](SnakeDurationSimulation.json)
- 重现模拟并更新表：Scripts/estimate-snake-duration.sh --write
- 快速完整性 / 过期检查：Scripts/check-snake-duration-estimates.sh

生成脚本使用不可变的生产源码副本，写入前复核哈希。完整性检查核对真实地图拓扑、真实速度及全部原始分位数，并拒绝与引擎不一致的旧数据。报告中的 repository base commit 是生成时工作分支的基点，生产源码以 engineSHA256 为准。

## 动态环路与铺满性质

先将可玩区域划分为相邻的 2 × 2 小块，每块构造四格小环，再沿随机生成树逐条合并相邻块的小环。每条树边删除两个环相向的边并接上两条邻接边；每次把两个不同分量合为一个更大的环，最终覆盖所有可玩格。围墙内场从 (1, 1) 配块，互通边缘允许跨缝配块。地图图案为这项铺满性质做了适配，并非对参考图逐格照搬。墙格永不加入环路；逻辑邻接、初始闭环和动态换边都必须拒绝墙格，空白边缘可以穿出。

蛇尾到蛇头沿闭环保持顺序。每步可以走合法邻居中的捷径，但不得越过食物或蛇尾；仅当本步不增长、蛇尾离开时可进入旧尾格。没有捷径时走安全的环路后继。

新食物出现后，有限搜索尝试成对的局部四格换边。中间拆分状态不会安装。最终候选必须为覆盖所有可玩格的单一合法闭环，保持完整身体次序，不增加头到食物的前向距离，并真正改变无向边集合。每颗食物最多尝试 136 次，失败即保留旧环。

两颗食物之间冻结闭环，前向食物距离每步严格减少，至多一圈内进食。每次进食增长一格，因此最终铺满。该性质针对当前六张地图及合法初始状态，不推广到任意障碍图。

设计参考 [John Tapsell 的安全环路与捷径](https://johnflux.com/2015/05/02/nokia-6110-part-3-algorithms/) 和 [Winning Snake: Design Choices in Multi-Shot ASP](https://doi.org/10.1017/S1471068424000267) 的安全循环思路。引擎为独立 Swift 实现，没有模型文件、外部求解器或网络依赖。

## 像素界面与动画

- LCD 底色和微像素轮廓。设置入口、策略选择和底部策略 / 填充文字栏均已移除。
- 本次效果分支 experiment/snake-stationary-wave 从 ca75bcb 分出。蛇身保留波浪外形，中段波形固定在已走过的路径上；内部纸色像素斑点随前进同速运动并贴合所在波峰 / 波谷，头部轻微侧摆，带像素眼眶的双眼标明朝向，末端收尖。展示不改变逻辑占用。
- 24fps 视觉插值，食物以 1.4 秒周期从小十字缩放成像素圆。蛇的纹理与头部相位使用真实步数和当前一步的进度，不另加按秒滚动的动画速度；活动单调时钟只用于食物呼吸和移动插值。暂停、后台和结束精确冻结；减弱动态效果时按逻辑格推进、关闭摆头和食物呼吸。
- 仅互通轴取模，墙轴直接插值并裁剪；微像素还按墙格裁切，蛇身与花纹不会渗入障碍。长蛇多次穿边不会产生跨屏连线。
- 渲染先固定完整路径 `[新头] + 上一步蛇身` 的控制点，再裁剪头尾；中段使用每格 8 个固定采样点，只有两端局部连接随移动伸缩。设完整路径参数为 u、已完成逻辑步数为 n，波形相位使用 u − n；跨 tick 时两者同步增加一，中段世界位置和微像素轮廓保持稳定。花纹固定在距头的材料坐标上，沿当前波浪位置取样，随头前进而流动。
- 选择页、按钮、休息提示、确认框统一使用中文像素字体、矩形边框、反色选择、硬像素投影和按下位移。没有系统 sheet、alert 或原生 Picker。
- 字体为 [Fusion Pixel](https://github.com/TakWolf/fusion-pixel-font) 12px 等宽简体中文原版，版本 2026.10.25，SIL OFL 1.1。字体与完整许可随应用打包，来源及校验值见 iOSLab/Fonts/FusionPixel/README.txt。
- VoiceOver 读出地图、速度档、估时及正确墙体拓扑。确认时后层控件同时禁用并从无障碍树隐藏，焦点进入弹层。窄屏 / 横屏可纵向滚动。

## 验证

生产引擎检查完成 2,752 局：六图各 256 局，加上 1,024 局小尺寸 / 奇偶尺寸 / 横纵边界组合和 192 局墙岛 / L 形 / 中央障碍检查，全部铺满，无自撞、穿墙或食物进度异常，目录地图所有种子均有真实中盘重规划。

独立估时运行另完成 1,536 局。完整性检查验证哈希、完整墙格集合、可玩格数、原始样本、分位数及真实速度换算，隔离副本保留相同墙数但替换一处墙坐标时，逐格校验会正确拒绝。

视觉检查覆盖成长、头尾、中段波浪固定、纹理同速流动、摆头、食物缩放、减弱动态效果、四面围墙、单轴互通、多次穿边及六图早期 / 半满的连续状态，确认蛇像素不会渗入墙格。会话检查覆盖初始不运行、运行中锁定选择、确认冻结、取消恢复 / 保留暂停、确认回选择页、前后台、通关和常亮恢复。

本分支另使用生产几何生成连续 28 帧、真实推进 3 格的直行与 U 弯慢放：远离头尾的固定区域轮廓分别为 0 / 147 和 0 / 588 像素变化，材料坐标固定的斑点沿波形前进相同 3 格，并可穿过转角。头部侧摆上限 0.04 格；150 个移动眼位采样均保留封闭眼眶。

模拟器已核对选择页不自启、换图估时变化、选速后开始、运行控件精简、重开确认 / 取消 / 返回选择、中文像素字体及单格外圈墙 / 内部障碍的实际显示；障碍地图最后一口会进入铺满休息提示。模拟估时不等于真机完整绘制性能或长期耗电测试。
